# Agent instructions

## Documentation and planning

- Use mainly md files and mmd supporting files, ask for permision if there is a good reason for using other files types.
- Write the shortest version that preserves all distinct ideas.
- State each idea once. Reference its original section instead of repeating it. 
- When organizing random thoughts or braindumps use logical groupings for easier human understanding.
- Include a short section like a table of contents at the top if the md is hard to gloss over for a human.
- Distinguish facts and hypotheses.

## User Learning

- Users highest goal is to develop his expertise as a Solutions Architect using AI Agents to do the coding for him. 
- If you come upon a problem, question or decision that is a consideration for a Solution Architect, notify the user for the lesson or area of intrest at the end of your message, with possible next steps in that direction if appropriate.
